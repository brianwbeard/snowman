# Snowman v1.6

This release adds:
- Win confetti using the same style/behavior as Learn to Readle.
- LTR-style two-step Reset Progress flow in the Progress panel.
- Clues setting changed from a checkbox to separate Yes / No buttons.
- A major clue-bank expansion, while continuing to use Learn to Readle answers.js as the single source of secret words.

Upload all five Snowman files. Do not copy answers.js into the Snowman repository; Snowman loads the shared Learn to Readle answer bank.
